# projects/

Product and internal projects, one folder each. Spawn with
`baab new project <slug>`.

Each project folder carries its own plan, state, roadmap, board, tasks, ship-log,
and architecture notes. `state.md` is the single source of truth for where a project
stands; `ship-log.md` is the append-only record of what shipped. `_registry.md` is
generated by `baab index`.
