# knowledge/

Concepts, lessons learned, and reference material — the things this business knows
that don't belong to a single project or client. Free-form area; write notes
directly here with frontmatter.

Use `type: concept` for explanations and `type: reference` only if you add it to the
type enum in `baab.config.json`. Remember the one-canonical-home rule: if a fact
already lives in a project or client note, link to it rather than restating it here.
