# Standards

The laws every note in this workspace obeys. Read them once; the tooling enforces
them so you don't have to remember every detail.

- [Frontmatter](./frontmatter.md) — the metadata header required on every note.
- [Naming](./naming.md) — how files and folders are named.
- [Lifecycle](./lifecycle.md) — how notes are created, updated, and retired.
- [Writing](./writing.md) — how to write so notes stay useful.

`baab doctor` checks the tree against these. A clean workspace has zero errors.
